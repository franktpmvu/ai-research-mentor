# 趣味探索軌（wild）

> 目錄：../CLAUDE.md

## 什麼時候用
- 每日推播固定 **3 篇與 CV/LLM/Diffusion 無關**的有趣論文——純粹的想法維度擴張，防止推薦對主領域過擬合。

## 怎麼做
1. 選「**獨特方法論**」或「**反直覺結論**」的論文：巧妙的實驗設計、出人意料的因果識別、優雅的證明、顛覆常識的實證發現。survey 不推。
2. 領域完全不限、越廣越好，非自然科學尤其歡迎（歷史、考古、藝術史、語言學、社會學、人類學、法學、音樂學、體育科學、廚藝科學……）；三篇之間領域也要分散。
3. 看 `daily_brief` 的「近 45 天 wild 已推主題」，**避開同主題反覆**（不同論文但同一主題也要避開）。
4. 核實出處（`refcheck.md`）→ `check_dup --title .. --url ..`。
5. `push_log` 寫成 `pid::wild::<標題>::<url>`（第三欄是標題，第四欄 url 一律要附，才能靠 URL／arXiv id 擋重推）。

## 輕量制（和其他軌的差別）
- **免 anchor**（刻意不要求回接主領域）。
- **免 mem_add、免 rubric、不進知識圖譜**、不出深度題、不參與升級。
- 若某篇 wild 恰好能回接主領域機制 → 可隔日轉為 xdomain 正式推（補 mem_add＋rubric＋anchor）。

## 呈現格式
標題＋連結 ／ 一句話「為什麼有趣」（方法論哪裡獨特、結論哪裡反直覺）／ ﹝領域﹞標籤。不套四段結構。

## 驗收標準
- 3 篇、領域彼此不同、都不是近 45 天已推主題。
- `push_log` 每篇都有第四欄 url 且已核實。

## 存放位置
- 只寫 `push_log.json`（30 天後自動歸檔到 `push_log_archive.json`，防重仍會掃）。
