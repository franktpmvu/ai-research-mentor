# 順帶驗收舊概念（recall）

> 目錄：../CLAUDE.md

原則：**不另外抽考**。討論新論文時，順便驗收它用到的舊概念——舊概念被新問題「用到」時才驗收。

## 什麼時候用
- 使用者對某篇論文有實質互動時。
- 使用者只想打卡、沒力氣的日子：**完全不做**。
- 使用者說「三篇都不喜歡」或主動說「考我」「幫我複習」→ 改走 `review_mode.md`（以概念為單位）。

## 怎麼做
1. `python3 mentor.py recall_related --paper <這篇的 pid>` → 列出它在知識圖譜上的先修（往上 3 層）與同技能、已通過的舊概念，含上次評語和舊盲區。**只給導師看，不貼給使用者**。標「✅該驗收了」的優先。
2. 讀使用者回答，對每個「該驗收」的舊概念判斷：
   | 使用者的回答 | 做法 | 記錄 |
   |---|---|---|
   | 主動講到且講對（沒被提示） | 不用另外問 | `--how mentioned --result pass` |
   | 有講到但含糊或錯 | 照 `socratic.md` 追問（更窄、不給答案） | 講對 → `--how followup --result pass`；仍錯 → `--result fail --blindspots ".."` |
   | 沒講到但這篇需要它 | 討論告一段落時最多問 **1 題**橋接問題 | `--how asked` |
   | 跟這次討論無關 | 不硬問 | 不記錄 |
3. 指令：
   `python3 mentor.py recall --paper <舊概念 pid> --result pass|fail --how mentioned|asked|followup --depth <0-4> [--note ".."] [--blindspots "a||b"]`

## 計分（刻意不懲罰）
- 通過 → 下次「該驗收」的間隔拉長：3 → 7 → 30 → 90 → 180 天；技能地圖可升到 4／5。
- 答錯一次 → 只記盲區、間隔歸零，不扣分、不降級。同一概念**連續兩次**答錯才算一次 fail。
- 不給使用者看「待考清單」或「還欠幾題」。

## 驗收標準
- 一次討論中額外發問的橋接題 ≤ 1。
- 同一天已討論過的概念沒有被再問。

## 存放位置
- `learner.json` 的 qa_record／skill_map（間隔由紀錄推導，不另存排程）。
