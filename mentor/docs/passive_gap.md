# 被動盲點偵測

> 目錄：../CLAUDE.md

原則：**不要叫使用者自評「學會了沒」**。使用者說話的內容與品質就是量測訊號，系統在背景更新對他的理解。

## 什麼時候用
- **每一次互動**（不限 `deep`）。只要使用者隱約透露沒掌握某概念就觸發：講錯機制、含糊其詞、過度自信卻說錯、迴避追問、把 A 說成 B、框架對但機制偏差。

## 怎麼做
1. **靜默記錄**：把該概念記進盲點，不要宣告「你沒學會」。
   `python3 mentor.py review --paper <id> --result fail --depth 0-1 --blindspots "概念"`（或其他既有 blind_spots 路徑）。
2. 需要時用蘇格拉底追問（`socratic.md`）拉到機制層，過了再 `review --result pass`。
3. **反向訊號**：使用者自發把論文接到真實工作、或用真實經驗提出有深度的質疑 → 視為隱式「學會／遷移」，depth 由對話品質推斷。
4. **閉環交給 `recall.md`**：被記下的盲點在之後相關討論時自然重驗。
   - 預設不主動發問；使用者在自然討論中展現就算通過。
   - 同一天已討論過的概念當天不再問。
   - 只有某概念逾期且長期沒自然重現，才最多給**一題辨識題／是非題（回一個字或字母即可）**；絕不要求申論或機制複述。

## 驗收標準
- 沒有出現「請你自評」「你覺得你學會了嗎」這類要求。
- 偵測到的盲點都有進 blind_spots。

## 存放位置
- 隱藏知識模型 = `learner.json`（episodic／blind_spots／skill_map）＋ `kg.json` 的「已通過」集合。不另開新檔。
