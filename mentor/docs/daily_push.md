# 每日主研究軌推播（Daily Push）— docs/daily_push.md

> 入口：../CLAUDE.md。本檔涵蓋每日 CV/LLM/Diffusion 主研究軌推播的完整規則：組成、記憶系統、知識圖譜先修守門、跨域/金融/wild 三個常設軌。

---

## Core Objectives
1. 制定並追蹤 52 週長期學習藍圖（`roadmap.json`，**滾動擴充**：某週目標空白時由 LLM 生成並以 `roadmap_set` 寫回）。
2. 每日推薦以「想法轉變」為導向：3 篇主領域論文（CV、LLM、Diffusion 各一）+ **1–3 篇跨域鏡子（越多越好）** + **1 篇金融鏡子** + **3 篇趣味探索 wild（與主領域無關）**。主領域/跨域/金融每一篇都要能回接一個主領域機制；wild 軌**刻意不設**回接約束（見趣味探索軌）。**組成由 `push_log` 程式化驗收。**
3. 嚴格執行「進度守門機制（Progress Gating）」：未通過理解評估（depth≥2），絕不推進該領域進度。
4. 維護**層級時間記憶**，讓每日推薦延續脈絡、不重複、廣跳躍、並補強盲區。

## 層級時間記憶（Hierarchical Temporal Memory）

導師記憶分五層，重要文獻會**逐層向上鞏固**：

```
week（近一週·7天） → month（近一月·30天） → half_year（近半年·182天）
    → year（近一年·365天） → long_term（長期核心·永久）
```

- 新讀到的論文/洞見以 `mem_add` 進入 **week** 層（同時記 `layer_entered`），並寫入審查標準 rubric。
- **升層條件（2026-07-07 修訂，漸進鞏固）**——每次 `mem_consolidate`：
  - **資格**：seen_count≥2 或 學習者已通過該篇（episodic passed）或 importance≥7；
  - **停留**：且必須在目前層停留 ≥ 該層窗口的一半（week 層至少 3 天）——**importance 高只是資格，不能免除停留**；
  - **long_term 入口額外門檻**：（學習者通過 且 imp≥8）或 seen_count≥3——長期核心必須經過時間與理解的雙重考驗；
  - 過期且不重要者淡出；每次最多升一層。
- 再次遇到同一篇 → `mem_add` 強化（seen_count+1、importance 取大），自然累積升層資格。

## LLM 即評估器（LLM-as-Judge，取代關鍵詞比對）

**你（LLM）就是評分器。** 不要依賴機械式關鍵詞比對（舊 `assess` 已降為離線後備）。

- 每次把論文寫入導師記憶時，**同時撰寫該論文的審查 rubric**：
  `mem_add ... --rubric "點1||點2||點3" --questions "問1||問2"`。
- 評估時：`python3 mentor.py rubric <paper_id>` 讀出審查標準 → 對照學習者回答判讀 → `review` 記錄裁決：
  ```
  python3 mentor.py review --paper <id> --result pass|fail \
      [--depth 0-4] [--domain cv|llm|diffusion] \
      [--blindspots "概念1||概念2"] [--note "一句評語"]
  ```
  depth：0–1 表層 / 2 機制 / 3 推導 / 4 批判。
- **深度守門（程式 enforce）**：pass 但 depth<2 → 不計升級分數、不推進領域（`review` 會警告）；
  `learner_state` 升級只計 depth≥2 的 pass（淺過另列「淺過(不計分)」）。

## 知識圖譜 — 先修依賴守門（Knowledge Graph / Prerequisite Gating）（2026-07-16 確立）
> 動機（使用者反饋）：粗粒度 A/B/C 等級太鈍，會放行跳級——例：Diffusion=A 就推 EDA，但使用者連 EDM、ODE/SDE 都沒看過，完全無法下手。病灶在**搜到的新論文（mem_add 進來的 pid）從不進任何先修圖，等級守門形同虛設**。解法：建持久化**先修依賴 DAG `kg.json`**，推薦時逐篇程式化守門。

**核心規則（北極星第二支柱「深度·錨定」的程式化）：**
- **節點**：每個論文/概念是一個 node（key=pid），欄位 `{title, domain, level, prereqs[], spontaneous, url, note}`。
- **解鎖判準**：`passed = 該 pid 有 depth≥2（機制層）的 review pass`（深度不打折）。由 episodic（含歸檔）qa_record 自動推導，不需手記。
- **前沿（frontier）**＝尚未通過、但**先修全部通過**的節點。主領域推薦的天花板。
- **守門硬規則**：**main 三篇每篇推薦前必跑 `kg_check --id <pid>`**：🟢（FRONTIER/OPEN）才可推；🔴 LOCKED（先修未過）**禁止跳推**，改推它的先修前沿（exit 3）；⚠ UNKNOWN（未建節點，exit 2）→ 先 `kg_add` 把它依引用/概念依賴放進圖譜相應位置再判。
- **守門已程式化雙保險（2026-07-16(二)，「使用者永遠不該看到鎖定論文」）**：kg_check 靠自律會漏（07-16 當日即漏推 eda-arb/infokv 兩篇 LOCKED）。現在 `push_log` 對每篇 main 程式化驗 KG——LOCKED/UNKNOWN 與缺 anchor 同級，exit 3；且**呈現給使用者之前必跑 `push_log --dry` 預檢**（完整驗組成/anchor/KG、不寫檔），預檢未過就換片，鎖定論文在呈現前即被攔下。
- **搜到新論文即入圖**：主領域 `mem_add` 後**同時 `kg_add`**，依該論文的**引用與概念依賴**接上先修邊（可分叉、可跳接）。找不到明確先修就當入門節點（prereqs 空）。
- **刻意保留的跳躍/點火例外**（呼應第一支柱「廣度·點火」，避免「先修焊死一切」造成過擬合）：
  - 跨域鏡子、金融鏡子、以及任何**憑空產生的跳躍連接**，`kg_add --spontaneous` 標記 → **豁免先修守門**（kg_check 回 🟢 OPEN）。這類節點本就是刻意的概念碰撞，不受先修鏈約束。
  - **wild 軌完全不進圖譜**（純點火，輕量制）。
- 一句話：**先修 DAG 焊住主領域深度（禁止跳級），spontaneous 節點與 wild 軌保留跳躍自由。**

指令：`kg_seed`（首次建骨幹）、`kg_add`（放新節點/接邊）、`kg_link`（增刪先修邊）、`kg_check`（守門，推薦前必跑）、`kg_frontier [domain]`（列可推前沿）、`kg_show [domain]`（樹狀看進度）。`daily_brief` 已內嵌各主領域前沿摘要。

## 省 token 分層原則

> 核心：**「驗證、輪轉、規劃骨架、執行盤點、推播驗收」全部程式化，不燒 token；LLM 只在真正需要智慧的地方介入**（寫 rubric／判讀回答／選新論文／寫 takeaway 與 anchor／生成週目標）。

- **每週一次·長讀規劃** → `python3 mentor.py week_plan new`
  排定「7 天想法軸 + 跨域來源輪轉」、各領域 level/phase focus、黑名單快照。
  **若 roadmap 無本週目標**（week 3 起常見）→ 依上週結果與該季主題生成三軌目標，
  `python3 mentor.py roadmap_set --week N --cv "..." --llm "..." --diffusion "..."` 寫回（D. 藍圖滾動擴充）。
- **每日·短讀執行** → `python3 mentor.py daily_brief`
  今日想法軸/跨域來源/金融連結領域、近 7 天黑名單（push_log ∪ episodic ∪ 近7天 mem_add）、盲區/趨勢、本週執行進度（**由 push_log ∪ episodic 日期推導**——推播本身就算執行，不依賴使用者互動）。
- 若某週忘了規劃，`daily_brief` 會提示先跑 `week_plan new`。

## 主線 1｜記憶自優化（導師端）
1. `python3 mentor.py daily_brief` → 推薦前必讀（短讀）。
2. 依今日想法軸上網搜尋三領域「最近的變化」，避免重複既有記憶。
3. **每篇候選先程式化驗重複**：`python3 mentor.py check_dup --title "..." [--url "..."]`
   → 🟢CLEAR 才推；🔴HIT 換一篇（複習例外須在推薦理由明講）；🟡疑似則人工確認。
4. 重要文獻寫回記憶＋rubric：`mem_add --title ... --domain <D> --url ... --summary ... --importance <1-10> --rubric "..." --pid <slug>`；趨勢用 `trend_add`。
5. **推播後必跑 `push_log`（A. 程式化驗收）**：
   `python3 mentor.py push_log --papers "pid::main||pid2::xdomain::<anchor>||pid3::finance::<anchor>||pid4::wild::<標題>||..."`
   - role ∈ main / xdomain / finance / wild / review；**xdomain 與 finance 的 anchor（回接的主領域機制）必填**；**wild 第三欄改填標題**（防重用，免 anchor）。
   - 驗組成：3 主領域 + ≥1 跨域 + 1 金融 + 3 wild（**2026-08-06 起無放寬情境，一律要求完整組成**；沒力氣深讀時走 `light_checkin` 超輕量打卡，不要期待 push_log 自動放寬）；**並對每篇 main 驗 KG 守門（LOCKED/UNKNOWN → exit 3）**；未達標 exit 3 → 補推缺軌/換先修前沿後同日重跑覆蓋。
   - **呈現給使用者前先跑 `push_log --papers "..." --dry` 預檢**（同樣驗收但不寫檔）——通過才呈現，使用者永遠不看到鎖定論文。
6. `python3 mentor.py mem_consolidate` → 升層/淡出，完成記憶自優化。

## 每日推播流程（Daily Push）

> **核心原則：每日推薦以「web search 找到的新論文」為主體**，curated `PAPERS`（`daily` 指令，已淘汰）只當靈感 scaffold。四條硬規則：**① 不重複 ② 求多樣 ③ 廣跨域 ④ 拒平庸 survey**。

**④ 拒平庸 survey（2026-07-14 新增，適用所有軌）**：原則上**不推 survey / review / 綜述類論文**。理由：許多新方法本身就是先做好 survey 才得出更好的方法——單純的整理彙總不帶來想法轉變，與北極星「跳躍思考·點火」相悖。**唯一例外**：該 survey 本身提出了突破性觀點或新方法（如提出新分類法且由此導出可操作的新框架、統一數學視角、揭示領域級反直覺結論）——此時推薦理由必須**明講「這篇 survey 的突破點是 X，不只是整理」**。判準：讀完摘要若只感覺「它把 N 篇論文整理得很齊」→ 不推；若感覺「它提出了一個別人沒講過的視角/方法」→ 才可推。

0. **完整性 + 讀今日計畫**：`integrity` → `daily_brief`（若提示本週無計畫 → 先 `week_plan new`，必要時先 `roadmap_set` 補該週目標）。
   **鐵則**：黑名單上的論文一律不重推。唯一例外：`deep` 未過關需複習——必須在推薦理由**明講「這是複習，因為上次卡在 X 機制」**。
1. 依 `daily_brief` 的**今日想法軸**與**跨域來源**搜尋，不直接照抄 curated `PAPERS`。
2. **多樣性**：每領域 1 篇符合 level 的論文，每篇先 `check_dup` 驗重複（🟢才推）。目標：知識樹**寬**——每天至少 1 個「使用者記憶裡沒出現過的新概念關鍵詞」。**選片時過濾 survey**（硬規則④）：優先原創方法/理論論文；survey 只在有突破性觀點時例外推薦並明講突破點。
2.5 **先修守門（2026-07-16，⑤硬規則·僅 main 三篇）**：主領域候選先 `kg_add` 依其引用把它放進圖譜相應位置，再 `kg_check --id <pid>`——🟢才可推；🔴 LOCKED 就**改推它的先修前沿節點**（daily_brief 已列各領域 🔓 前沿）。**禁止跳過未通過的先修**。跨域/金融用 `kg_add --spontaneous`（豁免）；wild 不進圖譜。
3. 主領域/跨域/金融每篇以含 rubric 的 `mem_add`（附 `--pid`）寫回導師記憶，並 `kg_add` 入圖（主領域接先修邊；跨域/金融加 `--spontaneous`）；**wild 3 篇免 mem_add／免入圖**（輕量制，只 check_dup + push_log）。
   **每日組成＝3 主領域 + 1–3 跨域鏡子 + 1 金融鏡子 + 3 趣味探索 wild**；跨域來源與金融連結領域由 `daily_brief` 輪轉指定；wild 領域自由發揮、越廣越好。
3.5 **呈現前預檢（2026-07-16(二)）**：`push_log --papers "..." --dry`——程式化驗組成/anchor/**main 的 KG 守門**但不寫檔；未過（exit 3）就換掉 LOCKED 論文/補缺軌，**通過才進下一步呈現**。
4. 呈現給使用者。（推播本身不放任何考題；舊概念只在使用者回覆討論時順帶驗收，見 `docs/learner_eval.md`「順帶驗收舊概念」。）**主領域/跨域/金融每篇一律用「三段結構」（2026-08-08 確立，不可用「把 ooo 改成 xxx」式的結論句帶過）**：
   - **① 問題背景**：這個領域原本卡在什麼問題？為何重要？痛點的**機制成因**在哪（不是症狀，是「為什麼會這樣」）。
   - **② 核心發想（抽象理解）**：這篇的關鍵 insight／類比／視角是什麼？**為什麼這個想法能解掉①的卡點**（講清楚因果，不只列做法）。
   - **③ 技術細節**：實際怎麼做的（公式/演算法/關鍵設計選擇與其代價）；跨域/金融這段須明確**回接主領域機制（anchor）**。
   末尾補一行：推薦理由（關聯藍圖、記憶脈絡或昨日進度；**複習須明講「上次卡在 X 機制」**）＋ ﹝想法軸或借用領域﹞標籤。
   判準：讀者看完①②要能回答「問題是什麼、為何這招管用」，而不是只記得一句改動摘要。
   - **問題優先原則（2026-11-05 使用者回饋強化）**：①一定要先把「問題是什麼、卡在哪、為何重要」講到讓人有感、有畫面，這是每篇的賣點；**數學／公式只是解那個問題的工具**，不是賣點。不要一上來就鋪數學，也不要以「這篇數學很漂亮」當推薦理由。公式放在②③、且每個符號都要說它在解①的哪一塊；能用白話或類比講清楚機制時，優先白話，數學只在白話講不精準時才登場。判準：若讀者讀完只記得「有一堆公式」而答不出「原本的問題是什麼」，這篇就寫失敗了。
   **wild 維持輕量**：標題+連結 / 一句話「為什麼有趣」/ ﹝領域﹞標籤（不套三段）。
5. **`push_log` 驗收組成、anchor 與 main 的 KG 守門**（見主線 1 第 5 步）——未達標就補推/換先修前沿再重跑。
6. 結尾附三行提示：
   - 「有興趣的論文？回覆 `teaser <paper_id>`」
   - 「想直接深入？回覆 `deep <paper_id>`」
   - 「今天沒空？明天繼續，習慣 > 完美 ✓」
7. 收尾：`mem_consolidate` + `learner_state` + `snapshot`。
8. **使用者回覆「done」／今天結束了 → 一律 `light_checkin`**（見「極輕量模式」一節）：今天若真的有討論機制／嘗試攻略論文，先做 `review` + `journal_add` 詳細記錄，`light_checkin` 仍照樣執行一次作為當天互動的通用標記（合併寫入、不會覆蓋推播內容）；若只是看了看，`light_checkin` 就是唯一需要的紀錄。

## 跨域鏡子（Cross-Domain Mirror）— 常設推播軌
> 使用者明確偏好「借道他山」：引入其他領域**自身的方法論/理論**重看 CV/LLM/Diffusion。來源領域大幅放寬，只要有一點方法可借就算數；跨域越多越好。

- 每日夾帶 **1–3 篇**：鼓勵每主領域各配一篇、來源各不同（`daily_brief` 列出當日 3 個輪轉來源與對應主領域）。找不到夠好的可少於 3 篇，但至少 1 篇。
- **廣度優先，來源每天輪換**：物理、化學、生物神經、演化生態、數學、資訊論、控制/訊號、經濟博弈、複雜系統、認知語言、運籌、社會學……（非窮舉）。
- **硬約束（2026-07-09 修訂，方向鎖定——「拿著槌子看什麼都是釘子」問題）**：挑的論文必須是來源領域**自身的方法論/理論/數學結構**（該領域的經典或前沿概念、模型、證明手法），**不是「把 CV/LLM/Diffusion（或任何 AI/ML 模型）應用到那個領域」的論文**。我們要借的是別的領域「怎麼想問題、怎麼證明、怎麼建模」的方法論本身，不是看到別的領域也順手把深度學習套進去的論文——那仍是同一根槌子，不是真正的跨域點火。
  - ❌ 不推：用 GNN/Transformer 做分子動力學或蛋白質結構、用深度學習做氣候/氣象模擬、用 ML potentials 加速分子模擬、用神經網路解 PDE 這類「AI 模型應用在 X 領域」的論文——即使來源領域是化學/物理，這仍是 AI 論文，不是該領域的方法論。
  - ✅ 要推：該領域**不涉及 AI/ML** 的經典或前沿方法論/理論，例如統計物理的重整化群與相變、生態學的競爭排除/可利用性理論、控制理論的李亞普諾夫穩定性與回饋、資訊論的率失真理論、演化動力學的複製方程、非平衡熱力學的熵產生、社會網絡的擴散/滲透理論、認知語言學的框架理論——然後由**我們**主動借它的思維方式/數學結構，反過來重講 CV/LLM/Diffusion 的某個機制。
  - 判準：讀完摘要若感覺「這其實是一篇 AI/ML 論文，只是套用在別的領域」，就不算跨域鏡子；若感覺「這篇論文完全不談 AI，但它的核心想法讓我聯想到某個機制」，才是我們要的。
- **借法不限整篇跨域論文**：借一個他領域的想法/類比/工具重講三軌某機制即可，不需要整篇論文都用得上。
- 選片準則：優先挑同時能鞏固基礎的角度。
- 每篇以含 rubric 的 `mem_add` 存入記憶；**`push_log` 時 role=xdomain 且 anchor 必填**（從哪個領域、借了什麼**方法論/理論結構**、重講哪個基礎機制）。

## 金融鏡子（Finance Mirror）— 常設推播軌
> 金融是「跳躍思考」的另一條專屬來源，方向是**用金融/經濟學自身的數學理論**重講三軌機制——不是用 AI 模型去做金融任務。

- 每日**固定 1 篇「金融理論 × 主領域」**；連結領域由 `daily_brief` 輪轉指定（llm/diffusion/cv）。
- **硬約束（2026-07-09 修訂，方向鎖定）**：借的必須是**金融/經濟學本身的學理與數學結構**（隨機微積分、無套利定價、鞅論與測度變換、市場微結構理論、投資組合最適化、資訊不對稱賽局論、選擇權定價 PDE、random matrix theory、Kelly 準則等），用它去解釋/重講 CV/LLM/Diffusion 的某個機制。**方向是 finance theory → 主領域機制，不是主領域模型 → 金融應用**。
  - ❌ 不推：LLM/Transformer 預測股價或讀 order book 做價格預測、VLM 讀 K 線圖做視覺預測、diffusion 生成金融時序——這些是「把 AI 模型套用在金融任務上」，是量化金融應用，不是我們要的跳躍方向，一律不算金融鏡子（若硬要提可歸類為 xdomain，但 anchor 需明確說借了金融的什麼數學結構，而非模型架構本身）。
  - ✅ 要推：例如 Black-Scholes PDE／反向 SDE 與 score-based diffusion 的生成過程的數學同構；鞅表示定理與序列決策中的 value function；無套利定價的測度變換（Girsanov）與 normalizing flow 的變數變換；市場微結構的資訊不對稱模型與 attention 的資訊篩選機制；投資組合理論的均值-變異數權衡與多目標訓練的 loss 權衡。
- `mem_add` 時 domain 記所連結主領域、tags 標 `finance`；**`push_log` 時 role=finance 且 anchor 必填**，anchor 需寫明「金融理論 X ↔ 主領域機制 Y」（哪個數學結構、對應到哪個機制），不得只寫金融應用場景。

## 趣味探索軌（Wild Track）— 常設推播軌（2026-07-11 新增）
> 動機：使用者反饋「推薦一定要跟主領域有關」開始有偏無聊的跡象。wild 軌是**完全自由的點火區**——每日固定 3 篇**與 CV/LLM/Diffusion 無關**的有趣論文，防止推薦系統對主領域過擬合。

- **選片準則**：聚焦「**獨特方法論**」或「**反直覺結論**」的論文——例如巧妙的實驗設計、出人意料的因果識別、優雅的證明手法、顛覆常識的實證發現。survey/綜述同樣不推（硬規則④）——wild 要的是原創的趣，不是整理的全。
- **領域完全不限、越廣越好**：非自然科學尤其歡迎——歷史、考古、藝術史、語言學、社會學、人類學、法學、音樂學、體育科學、廚藝科學……三篇之間領域也盡量分散。
- **輕量制（與其他軌的關鍵差異）**：
  - **免 anchor**：不需要回接主領域機制——這是刻意設計，不是遺漏；
  - **免 mem_add / 免 rubric**：不進導師記憶、不出深度題、不參與守門與升級；
  - **仍要 `check_dup`**：每篇先驗重複（check_dup 會掃 push_log 含歸檔，wild 推過的不會重推）；
  - **`push_log` 記錄**：`pid::wild::<標題>`（第三欄填標題供防重，非 anchor）。
- **呈現格式**：標題+連結 / 一句話「為什麼有趣」（方法論哪裡獨特、結論哪裡反直覺）/ ﹝領域﹞標籤。不需推薦理由回接藍圖。
- **與跨域鏡子的分工**：跨域鏡子＝借他域方法論**重講主領域機制**（必回接）；wild＝**純粹的想法維度擴張**（禁止回接要求）。若讀完發現某篇 wild 恰好能回接主領域機制，那是意外之喜——可隔日轉為 xdomain 正式推（補 mem_add+rubric+anchor）。
